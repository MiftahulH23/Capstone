# Client – Esteh Indonesia

Frontend React yang dibangun dengan [Vite](https://vite.dev) dan Tailwind CSS.

## Menjalankan

```bash
npm install
npm run dev      # server pengembangan di http://localhost:3000
npm run build    # build produksi ke folder build/
npm run preview  # cek hasil build
```

Backend (folder `server/`) harus berjalan di `http://localhost:5000`.
